## 2026-05-14 - Refactoring array iterations for performance
**Learning:** Consolidating multiple data aggregation passes (e.g., separate `.reduce()` or `.filter()` calls) into a single primary iteration significantly reduces processing overhead and intermediate allocations in server-side data handlers. When refactoring array iterations for performance, avoid introducing new `Array.includes()` checks against static sets inside the loop. This introduces unnecessary O(N*M) overhead; rely on direct condition checks or hoist the array into an O(1) `Set` instead. Also, avoid unnecessary .push() array allocations when only counts are needed for the score.
**Action:** When asked to optimize performance and replace nested filters, prefer tracking integer counts via nested loops instead of pushing to temporary arrays. Log performance metrics in PR descriptions.
