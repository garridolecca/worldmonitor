## 2024-05-24 - [Avoid Set Iteration in jaccardSimilarity for O(1) Memory Allocation]

**Learning:** The news clustering inner loop (`clusterNewsCore`) in `src/services/analysis-core.ts` relies heavily on `jaccardSimilarity` (`src/utils/analysis-constants.ts`). Calling `new Set([...a].filter(...))` and `new Set([...a, ...b])` inside `jaccardSimilarity` creates intermediate arrays and sets, allocating memory linearly proportional to the input size (`O(N)`) on every call. In an `O(N^2)` inner loop, this triggers excessive garbage collection, bottlenecking overall execution speed.
**Action:** When working in high-frequency inner loops (like `O(N^2)` operations), strictly avoid creating new arrays or sets just to calculate intersection and union lengths. Iterating through the smaller set to count intersections, then using the inclusion-exclusion principle (`|A U B| = |A| + |B| - |A ∩ B|`) computes the Jaccard similarity in `O(1)` space complexity without the GC overhead.
