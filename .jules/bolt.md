## 2024-05-18 - Consolidate iterative operations to avoid array allocation overhead
**Learning:** In performance-critical functions mapping over large arrays (such as calculating aircraft summaries for different theaters), chaining multiple `Array.filter` calls or executing several `.reduce` passes over the same dataset introduces unacceptable O(M*N) complexity and allocates unnecessary intermediate arrays, straining the garbage collector and causing frame drops.
**Action:** When deriving multiple aggregates from the same array (e.g., counting multiple flight types or deriving sums for distinct metrics), consolidate the operations into a single imperative pass (`for` loop). This allows computing `total` incrementally, building sub-dictionaries (like `byOperator`), and executing multiple aggregations within a single O(N) traversal.
