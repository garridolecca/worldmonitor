## 2024-06-05 - Array Pass Consolidation
**Learning:** The codebase previously contained several instances where arrays were scanned multiple times consecutively using `.filter().length` to count categories (e.g., `src/services/military-surge.ts` counting aircraft types, `src/components/StrategicPosturePanel.ts` counting vessel types). This leads to O(N*M) time complexity where N is array length and M is the number of categories.
**Action:** When filtering or counting multiple categories within a single collection, use a single imperative O(N) `for...of` loop with a switch or if/else chain to increment individual counters. This pattern avoids redundant iterations and intermediate array allocations, significantly improving performance for large data streams like flights and vessels.
