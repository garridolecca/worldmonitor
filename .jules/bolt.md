## 2026-05-26 - military-surge.ts Array.find and filter replacements
**Learning:** Found that static constant arrays like `POSTURE_THEATERS` and `OPERATOR_HOMES` were being unnecessarily scanned using `Array.find()` inside O(N) loops. Also found seven separate `Array.filter()` passes iterating the same flight objects. These are typical O(N*M) or multi-pass O(N) array overheads that scale poorly with lots of military flight datasets. Replacing them with O(1) `Map` lookups and a single consolidated switch-loop completely solved the issue.
**Action:** Always inspect array iterations inside hot data transformation pipelines (especially map or filter loops over large datasets). If looking up static domains, hoist a `Map` at the module level. If aggregating multiple subsets, use a single imperative pass with an `if/else` or `switch`.
